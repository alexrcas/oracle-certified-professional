# Trabajando con Java y tipos de datos

## Declaración e inicialización de variables

La declaración se compone del tipo + nombre de la variable:

```java
int miVar;
```

Es posible declarar e inicializar en la misma línea:

```java
int p = 10;
```

También es posible hacer declaración múltiple e inicialización:

```java
int a = 5, b = 10;
int p, s, a = 10; // también pueden mezclarse inicializadas y no inicializadas
```

### Identidicadores

Un identificador puede ser **cualquier combinación de letras (case insensitive), números y los caracteres `$` y `_`. Aún sobre esto, existen algunas restricciones:

* No pueden usarse palabras reservadas: new, break, long... técnicamente serían nombres válidos pero son palabras reservadas. Como curiosidad, la expresión *goto* no tiene ninguna funcionalidad en Java pero es una palabra reservada.
* No pueden empezar por un número.

```java
int _1; // OK
char break; // Error
int 3aj; // Error
float car.t; // Error
long goto; // Error
long  gototouch; // OK
```

Java es **case-sensitive** y los identificadores no son una excepción:

```
Las siguientes variables son diferentes entre sí y pueden coexistir:
int theBall;
int theball;
int Theball;
```

### Ámbito de una variable

* Las variables de clase, atributos o campos, son visibles en toda la clase.
* Las variables locales o de método, son solo visibles dentro de ese método.

```java
class MiClase {

    int n;

    public void metodo() {
        int n;
        n = 10; //se refiere a la variable n dentro del método, no la declarada como atributo en la clase
        this.n = 20; // atributo de la clase, referenciado usando this
    }

}
```

* Las variables locales o de método **NO se inicializan por defecto**.
* Los atributos sí se inicializan por defecto, siguiendo las siguientes reglas:
    * Enteros: 0
    * Decimales: 0,0
    * Booleanos: false
    * Tipo char: `'\u0000'`
    * Objetos: null


### Variables primitivas vs objetos

* La variable primitiva contiene directamente el valor.
* La variable de tipo objeto contiene una referencia: una dirección de memoria donde está el objeto.

```java
int n = 200 // n contiene 200
Object obj = new Object() // obj contiene en realidad el valor, por ejemplo, 0x315A, la dirección de memoria donde está el objeto
```

Entender lo anterior es muy importante porque implica que en las asignaciones, en los tipos primitivos copiamos realmente el valor, pero en los objetos lo único que estamos copiando es el puntero y no creando una copia del objeto.

#### Literales

Un literal es cualquier número "hardcoded", como por ejemplo `int a = 342`, donde `342` sería un literal.
No solo los números del sistema decimal pueden ser representados por literales. Java soporta otros tipos:

```java
289 // literal
0435 // octal, al empezar por 0
0xAF05 // hexadecimal
0b10001100 // binario
```

Como curiosidad, puede utilizarse el caracter `_` para facilitar la lectura de los literales

```java
int a = 3_000;
int hex = 0xA7_03;
```

Sin embargo, existen restricciones, y es que el caracter `_` no puede aparecer al inicio, al final, junto al punto decimal, o junto al prefijo en el caso de hexadecimales o binarios. Las siguientes declaraciones son todas incorrectas:

```java
int a = _1000;
int b = 1000_;
double c = 10_.5;
double d = 10._5;
int hex = 0x_A703;
byte n = 0b_1001;
```

Sin embargo, **existe la excepción con el octal**:

```java
int oct = 0_345 // válido aunque el '0' aquí sea un prefijo
```
