# Curso Oracle Certified Professional

Este repositorio es un diario de seguimiento y estudio del curso *Preparación para obtención de la certificación oficial de Oracle, versiones Java 11, Java 17 y Java 21* de *Antonio Martín Sierra* [en la plataforma Udemy](https://www.udemy.com/course/curso-certificacion-profesional-desarrollador-java-se-11/).

El objetivo es, por un lado, reforzar e interiorizar mejor el aprendizaje al tener que transcribir las lecciones y los ejercicios, y por otro lado, crear una versión escrita del curso de modo que sirva de guía para cualquier persona.

## Estructura del repositorio

El repositorio sigue la misma estructura y distribución del curso, la cual parece adecuada y bien elaborada. Se organizará en carpetas, una por cada sección del curso, y dentro de cada carpeta se encontrará un documento markdown con los apuntes de las lecciones que conforman dicha sección.
Cada sección puede tener una o más hojas de ejercicios. Se subirán también dichas hojas, cada una acompañada a su vez de otro documento con las soluciones.
